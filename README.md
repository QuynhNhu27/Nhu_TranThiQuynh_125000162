🎨 Điểm mình tập trung khi thiết kế
- Phong cách pastel: Màu sắc nhẹ nhàng, các thẻ nội dung bo góc và khoảng trắng thoáng mắt.
- Giao diện responsive: Dùng CSS Grid và Flexbox để bố trí nội dung phù hợp nhiều kích thước màn hình.
- Cấu trúc rõ ràng: Ưu tiên các thẻ HTML5 có ý nghĩa như header, main, section, article và footer.
- Tương tác bằng HTML/CSS: Menu thu gọn trên điện thoại, hiệu ứng chữ, hover và cuộn trang mượt.
- Dễ theo dõi: Các phần nội dung được chia thành từng khu vực riêng, có thanh điều hướng và nút quay về đầu trang.

🚀 Cách chạy website
Xem trên máy tính:
1. Nhấn Code → Download ZIP ở trang repository (sau khi mã nguồn đã được tải lên).
2. Giải nén và giữ nguyên cấu trúc thư mục.
3. Mở tệp index.html bằng Chrome, Edge hoặc một trình duyệt hiện đại.
Đây là website tĩnh nên không cần cài đặt Node.js, cơ sở dữ liệu hay chạy máy chủ riêng để xem giao diện.

Xuất bản bằng GitHub Pages:
1. Tải đầy đủ index.html, style.css và thư mục assets/ lên nhánh main.
2. Vào Settings → Pages của repository.
3. Trong Build and deployment, chọn Deploy from a branch → main → / (root) → Save.
4. Khi GitHub Pages triển khai thành công, website dự kiến có địa chỉ:
